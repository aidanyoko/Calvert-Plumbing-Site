# Calvert Plumbing and Backflow Services website

One-page demo site for Calvert Plumbing and Backflow Services in Pasadena, MD. Plain HTML, CSS and JavaScript with no build step.

## Files

- `index.html` page content
- `styles.css` all styling
- `script.js` contact form behavior
- `assets/logo.jpg` logo

## Preview locally

Open `index.html` in a browser.

## Before going live

- The contact form currently opens the visitor's email app. Replace it with a form service such as Web3Forms and add the access key.
- Replace the review buttons with the real Google review link.
- Confirm the domain, service area and business details with the owner.
